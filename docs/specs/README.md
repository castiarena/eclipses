# Feature specs

One file per feature, kept as a history of what was built and why.

- Name: `YYYY-MM-DD-short-feature-name.md`, dated when the spec was agreed.
- Start with a status line naming the PRs that built it.
- Don't rewrite a spec after it ships. If a later feature changes the decisions, write a new spec and link back.
